# FastDS

Made for Blender 5.1.2, might work on versions greater than 3.2 but this will be untested.

This is a Blender plugin made for The Legend of Zelda: Phantom Hourglass and The Legend of Zelda: Spirit Tracks that allows one to import and export Nintendo DS model/collision files.

WIP!

## Developement

We recommend using Astral's `ty` and `ruff` for linting/formatting Python files.
